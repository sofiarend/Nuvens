# Dicionário de Nuvens 

## Sobre o projeto 

O Dicionário de Nuvens  é um site educativo que tem como objetivo de apresentar os diferentes tipos de nuves existentes na atmosfera e suas classificações.
A proposta é ajudar os vistantes a conhecerem melhor as nuvens que observamos no céu, entendendo como elas se formam e quais condições climáticas podem estar relacionados a cada tipo.

## Objetivos

- Apresentar os principais tipos de nuvens.
- Explicar suas características e classificações.
- Compartilhar curiosidades sobre a formação das nuvens.
- Oferecer um quiz interativo para testar os conhecimentos dos visitantes.

## Tecnologias utilizadas

- HTML5: estruturação do conteúdo.
- CSS3: estilização e responsividade.
- JavaScript: interatividade, cálculos e validação de dados.
